## Bugs found & fixed (all in the uncommitted diff)
1. **pgsql/dist-electron bundle bloat** — `next.config.ts` pins `outputFileTracingRoot` to the project, so Next standalone copied the whole tree into `.next/standalone`, incl. a duplicate 133 MB `pgsql/` and (worse) `dist-electron/` itself (each build nested the previous installer → compounding). Fixed via `outputFileTracingExcludes` in `next.config.ts` + defensive strip in `scripts/electron-build.js`. Installers dropped from a would-be 549 MB to 260 MB.
2. **Missing DB credentials on generic build** — `electron-build.js` always writes a bundled `.env.local` (to bake `WVO_DEFAULT_TIER`), so a generic build shipped a **tier-only** file. Old `ensureEnvLocal` only generated creds when `.env.local` was entirely *missing*, so it skipped generation → no `DATABASE_URL` → bundled DB never initialized, server crashed at import. Fixed to check per-key.
3. **EPERM on Program Files install** — the app wrote `.env.local` into its own (read-only) install dir. Reproduced: installing Plus to `C:\Program Files\WhiteVanOps` → `EPERM ... open '...\resources\nextjs\.env.local'` startup error. **Fix:** `electron/postgres.js` now persists generated credentials to the per-user store `%APPDATA%\whitevanops\.env.local` (never the install dir) via new `loadOrCreateCredentials()`, and exports `DATABASE_URL`/`SESSION_SECRET` into `process.env` so the inline standalone Next server picks them up. Precedence: baked bundle creds → persisted store → freshly generated. Validated against the real module (generate-if-missing / stable-on-relaunch / baked-creds-win all pass). `backup.js` already prefers `process.env.DATABASE_URL`, so it still works.

## How licensing/activation works (context for testing)
- **Base activation** is an online gate: on first launch with no `%APPDATA%\whitevanops\license.json`, `electron/main.js` opens a GUI activation window that validates a base key against **Firebase Firestore** and writes an HMAC-signed `license.json` bound to the machine's hardware id. `startServer()`/DB init do NOT run until activated.
- **Plus** is a runtime tier flag: pre-activated via `WVO_DEFAULT_TIER="plus"` (Plus installer), or upgraded on a Base install by applying a signed `plus_license.json` (the `.exe` patcher, or paste-in JSON from `license-manager.js --plus`). `verifyPlusLicense` requires the plus payload's `licenseKey === the activated base key`. Signing secret is shared HMAC in `src/lib/license.ts`, `electron/main.js`, `electron-build.js`, `license-manager.js`.
